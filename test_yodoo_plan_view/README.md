# Yodoo Plan View Test

Тестовий модуль для демонстрації можливостей `yodoo_plan_view`.

## Моделі

### Building Floor (building.floor)
- **Поверх будівлі** з планом
- Наслідує `plan.view.mixin`
- Містить багато приміщень

### Building Room (building.room)
- **Приміщення** на поверсі
- Автоматично створює полігон на плані
- Може відкрити план з виділенням

## Використання

1. Встановіть модулі:
   - `yodoo_plan_view`
   - `yodoo_plan_view_test`

2. Перейдіть до меню **Building → Floors**

3. Відкрийте поверх та натисніть **Open Plan**

4. В режимі редагування:
   - **Select** - вибір полігонів
   - **Draw** - малювання нових полігонів
   - **Ruler** - вимірювання відстаней
   - **Pan** - переміщення плану

5. Налаштування:
   - **Grid** - показати решітку
   - **Snap** - прив'язка до решітки
   - **Zoom** - масштабування (Ctrl+Scroll)

## Демо дані

Модуль включає демо дані:
- 2 поверхи (Ground Floor, 1st Floor)
- 5 приміщень (Reception, Conference Room, Kitchen, Offices)
